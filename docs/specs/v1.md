# v1 — 最小 RAG 闭环

## 1. 版本摘要

- Nest + 前端壳；文档 CRUD（标题+正文）同步切块/向量；非流式 RAG 问答；Compose：Postgres(pgvector)+MinIO（未接）+pgAdmin。

## 2. 能力清单

| capability id | 说明 |
|---------------|------|
| `compose-deps` | 本地依赖 Compose |
| `compose-admin-ui` | pgAdmin + MinIO Console（见 add-compose-guis） |
| `document-crud` | 文档 CRUD + 同步向量切块 |
| `rag-chat` | stub 鉴权 + 非流式问答 |

## 3. 依赖中间件

- PostgreSQL 15 + pgvector；MinIO（预置）；pgAdmin（Compose GUI）；OpenAI 兼容 Embedding/Chat API

## 4. 前端页面

`/login`、`/documents`、`/documents/new`、`/documents/:id`、`/documents/:id/edit`、`/chat`

对应 OpenSpec：`openspec/changes/bootstrap-minimal-rag/`；管理端 GUI：`openspec/changes/add-compose-guis/`。
